# Веб-версия полностью на своём компьютере (Windows 11, Node.js и Apache)

Веб-версия это набор статических файлов (папка `www`). Их отдаёт Apache по адресу http://localhost/game-catalog/.
Данные каталога хранятся в браузере (IndexedDB) для этого адреса, на компьютере вне браузера ничего не хранится.
IGDB не принимает запросы прямо из браузера, поэтому рядом работает маленький прокси на Node.js; Apache пересылает ему запросы
по адресу /igdb/, так что для браузера всё на одном адресе (без CORS и смешанного содержимого). RAWG и SteamGridDB вызываются из браузера напрямую.

## 1. Node.js
1. Откройте PowerShell и выполните: `winget install OpenJS.NodeJS.LTS` (или скачайте LTS с nodejs.org и установите).
2. Закройте и снова откройте PowerShell, проверьте: `node -v` (нужна версия 18 или новее).

## 2. Apache
1. Установите Apache (Apache Lounge: apachelounge.com/download, архив распаковать в `C:\Apache24`; либо XAMPP). Дальше пути для `C:\Apache24`, поправьте под свой.
2. Если порт 80 занят, в `C:\Apache24\conf\httpd.conf` замените `Listen 80` на `Listen 8080` и `ServerName localhost:8080` (и дальше везде вместо http://localhost пишите http://localhost:8080).
3. Запустите `C:\Apache24\bin\httpd.exe` в PowerShell и откройте http://localhost/: должна появиться страница «It works!». Чтобы Apache запускался сам: `C:\Apache24\bin\httpd.exe -k install`, затем `net start Apache2.4` (от имени администратора).

## 3. Файлы приложения
1. Распакуйте `game-catalog-updated.zip`, например, в `C:\game-catalog`.
2. Скопируйте веб-версию в Apache и поставьте номер сборки:
   `powershell -ExecutionPolicy Bypass -File C:\game-catalog\tools\local-deploy.ps1 -Target "C:\Apache24\htdocs\game-catalog"`
3. Откройте http://localhost/game-catalog/: приложение должно открыться.

## 4. Прокси IGDB в Apache
1. В `C:\Apache24\conf\httpd.conf` уберите «#» перед строками `LoadModule proxy_module modules/mod_proxy.so` и `LoadModule proxy_http_module modules/mod_proxy_http.so`.
2. В конец файла добавьте:
```
AddType application/manifest+json .webmanifest
ProxyPass /igdb/ http://127.0.0.1:8787/
ProxyPassReverse /igdb/ http://127.0.0.1:8787/
```
3. Проверьте настройки: `C:\Apache24\bin\httpd.exe -t` (должно быть «Syntax OK») и перезапустите Apache.

## 5. Прокси на Node.js
1. Получите новые ключи IGDB: dev.twitch.tv/console/apps, Client ID и Client Secret (если секрет когда-либо попадал в чат или репозиторий, создайте новый кнопкой «New Secret»).
2. Откройте `C:\game-catalog\tools\start-igdb-proxy.cmd` в Блокноте и впишите Client ID и Client Secret. Адрес сайта оставьте `http://localhost` (при порте 8080: `http://localhost:8080`).
3. Запустите этот файл двойным щелчком. Окно должно остаться открытым и написать «Прокси IGDB: http://localhost:8787».
4. Автозапуск: Планировщик заданий, «Создать задачу», триггер «При входе в систему», действие «Запустить программу» `C:\game-catalog\tools\start-igdb-proxy.cmd`, галочка «Выполнять с наивысшими правами» не нужна.

## 6. Настройка приложения
1. В Chrome или Edge откройте http://localhost/game-catalog/ -> «Настройки».
2. В блоке «Ключи IGDB» в поле «Адрес своего прокси» впишите `http://localhost/igdb` и нажмите «Сохранить и проверить». Должно появиться «Ключи работают». Client ID и Secret в приложении указывать не нужно.
3. Ключ RAWG и SteamGridDB вводятся там же, как раньше.
4. Установка как приложения: значок «Установить» в адресной строке (Chrome и Edge). Адрес localhost считается безопасным, поэтому работают офлайн-режим и установка.

## 7. Обновление версии
1. Распакуйте новый архив поверх `C:\game-catalog`.
2. Снова выполните команду `local-deploy.ps1` из шага 3 (она меняет номер сборки, без этого браузер может показывать старые файлы).
3. В браузере закройте и откройте вкладку или приложение (при необходимости Ctrl+F5).

## 8. Данные и копии
- Данные принадлежат адресу и порту (`http://localhost`). Не меняйте адрес, не очищайте данные сайта в браузере.
- Регулярно делайте «Экспорт копии» в «Настройках». Перенос между компьютером, телефоном и GitHub Pages только через экспорт и импорт.

## 9. Если что-то не работает
- В приложении «Ключи не приняты»: проверьте Client ID и Secret в `start-igdb-proxy.cmd`, перезапустите прокси.
- Ответ forbidden: `ALLOWED_ORIGIN` не совпадает с адресом сайта (разный порт, лишний «/», заглавные буквы).
- 502 или «Нет связи с IGDB»: прокси не запущен или неверный порт; проверьте http://127.0.0.1:8787 (в браузере там будет «forbidden», это нормально) и `C:\Apache24\logs\error.log`.
- С другого устройства по адресу вида http://192.168.x.x установка приложения и офлайн-режим недоступны (браузер требует https). На телефоне пользуйтесь APK.
- Обложки и скриншоты IGDB из браузера могут не сохраняться в базу (картинки показываются по ссылке): сервер картинок может не разрешать такие запросы.
