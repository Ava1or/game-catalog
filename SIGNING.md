# Перенос ключа подписи в GitHub Secrets

Сейчас APK подписывается ключом из папки `android-signing/`: он лежит в публичном репозитории вместе с паролем.
Это значит, что любой может собрать APK с вашей подписью, и Android примет его как обновление вашего приложения
(с доступом к данным каталога на телефоне). Свой ключ в Secrets закрывает эту дыру.

## Шаги (один раз, около 10 минут)
1. **Сделайте копию данных в приложении**: Настройки, «Экспорт в файл», «Полная копия». Файл сохраните вне телефона.
2. На компьютере с Java создайте ключ (пароль придумайте длинный и запишите в менеджер паролей):
   `keytool -genkeypair -v -keystore my.keystore -alias gamecatalog -keyalg RSA -keysize 2048 -validity 36500 -storetype PKCS12 -storepass ВАШ_ПАРОЛЬ -keypass ВАШ_ПАРОЛЬ -dname "CN=Game Catalog"`
   Пароли хранилища и ключа должны совпадать: сборка использует один `KEYSTORE_PASS` для обоих.
3. Превратите файл в строку base64.
   Windows PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("my.keystore"))`
   Linux/macOS: `base64 -w0 my.keystore`
4. GitHub: репозиторий, Settings, Secrets and variables, Actions, New repository secret. Создайте три секрета:
   `KEYSTORE_B64` (строка из шага 3), `KEYSTORE_PASS` (пароль), `KEY_ALIAS` (`gamecatalog`).
5. Удалите из репозитория папку `android-signing/` (коммит с удалением).
6. Запустите сборку (Actions). В логе шага «Подпись» должна быть строка «Подпись личным ключом из GitHub Secrets»,
   а предупреждения про публичный ключ быть не должно.
7. **Переустановка:** Android не ставит APK с другой подписью поверх старого. Удалите старое приложение,
   установите новое и импортируйте копию из шага 1.

## Важно
- Файл `my.keystore` и пароль храните в безопасном месте и не коммитьте в репозиторий (он добавлен в `.gitignore`).
  Если ключ потерять, обновить приложение поверх уже установленного будет нельзя, только переустановить с импортом данных.
- Версия для браузера (GitHub Pages) от ключа не зависит.
