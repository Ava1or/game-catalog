КАТАЛОГ ИГР: СВОЙ СЕРВЕР ДЛЯ ДОМАШНЕЙ СЕТИ

Подробная инструкция по шагам: откройте файл ИНСТРУКЦИЯ.html (двойной щелчок, откроется в браузере).
Она же есть в самом приложении: Настройки -> Синхронизация и свой сервер.

Коротко:
  1. Распакуйте архив целиком в папку, например C:\GameCatalog (не запускайте файлы из архива).
  2. Если на компьютере нет Node.js: файл "1. Установить Node.js".
  3. Файл "2. Запустить сервер": появятся адрес и код доступа. Окно не закрывайте.
  4. На компьютере откройте в браузере http://localhost:8787
  5. В приложении на телефоне: Настройки -> Синхронизация -> введите адрес и код.

Если телефон не видит сервер: файл "3. Разрешить доступ в сети" (правый щелчок, запуск от имени администратора).
Все ваши данные лежат в папке data. Копию делайте, копируя эту папку.
