What this is and why you need it

Right now the catalog is stored only on the device where you use it: your phone does not know what you added on the computer, and the other way round. To keep the data the same everywhere, a small program, the server, runs on a computer. It is just a “smart shared folder”: your phone and other computers come to it, leave their changes and pick up the others'.

  • Everything works only inside your home network (over your Wi-Fi). Your data never goes out to the internet.
  • Without internet and without the server the app keeps working; the exchange simply does not happen. As soon as the server is reachable, the data evens out by itself.
  • The computer that runs the server must be turned on at the moment of the exchange.
What you need: a computer with Windows 10 or 11, home Wi-Fi (the phone and the computer connected to the same one), and about 20 minutes. You do not need to know much about computers: just repeat the steps in order.

Step 1. Download the archive and extract it

  1. Get the archive game-catalog-server-en.zip. The easiest way: it is already inside the app on your phone. Tap the “Download the server archive” button (it is at the very top of this guide and in the sync settings). The “Share” menu opens: send the archive to your computer, for example through Google Drive, email or “Saved Messages” in Telegram, or with “Nearby Share”. On the computer, open the message you received and download the file; it usually lands in the “Downloads” folder. In a browser on a computer, the same button downloads the file right away.
  2. Right-click the file and choose “Properties”. If there is an “Unblock” checkbox at the bottom of the window, tick it and click “OK”. (If there is no such checkbox, that is fine.) This reduces Windows warnings later.
  3. Right-click the archive again and choose “Extract All…” (in Windows 11 it may be hidden under “Show more options”).
  4. In the window that opens, click “Browse…”, choose drive C: and create a new folder named GameCatalog. Click “Extract”.
  5. The folder C:\GameCatalog opens. It contains files with numbers at the beginning of their names: “1. Install Node.js”, “2. Start server” and others.
Important: do not run files straight from the archive (by double-clicking the zip file). Always “Extract All” first. And do not delete the GameCatalog folder later: your data will be stored in it.

Step 2. Install Node.js (once)

Node.js is a free program the server needs in order to work. The easiest way to check whether it is installed is step 3: if it is not, the window will tell you. So you can go straight to step 3 and come back here if you see the message “Node.js was not found”.

Option A (easier)

  1. In the GameCatalog folder, double-click the file “1. Install Node.js”.
  2. A black window opens and the installation runs. If Windows asks for permission, click “Yes”. Wait for the message that everything is ready and close the window.

Option B (if option A did not work)

  1. Open the website nodejs.org in a browser.
  2. Click the big button labeled LTS (next to it it says “Recommended For Most Users”). The installer downloads.
  3. Run the downloaded file. In every window just click “Next” without changing anything, then “Install” and “Finish” at the end. If Windows asks for permission, click “Yes”.
After installing Node.js, close all black windows if any are open and go on to step 3.

Step 3. Start the server for the first time

  1. Double-click the file “2. Start server”.
  2. If Windows shows a blue window “Windows protected your PC”, click “More info” and then “Run anyway”. The file is safe: it is an ordinary text script that you can open in Notepad and read.
  3. A black window appears with a frame “GAME CATALOG: your server”. Two important things are in it:
    • The address, similar to http://192.168.0.15:8787: where to connect from the phone;
    • The access code, similar to k4m9x-p7w2h: a “password” you enter once in the app.
  4. If Windows shows the window “Windows Defender Firewall has blocked some features…”, tick “Private networks” (you do not need to tick “Public networks”) and click “Allow access”. This lets the phone reach the computer.
  5. Do not close this black window while you use sync: if you close the window, the server stops. You can minimize it. (Step 7 explains how to make the server start by itself when the computer is turned on.)
If the firewall window did not appear and the phone cannot connect later, run the file “3. Allow network access”: right-click it and choose “Run as administrator”. Once is enough, you will not need it again.

If you forgot the address or the code, double-click “4. Show address and code”: the window will show them again. The code is also written in the file config.json (you can open it with Notepad).

Step 4. Open the catalog on this computer

  1. On the computer, open any browser (Chrome, Edge, Firefox) and type in the address bar: http://localhost:8787. Your catalog opens, but it is empty for now.
  2. If you already have data somewhere else (for example, in the version on another website or in another browser), first make a full backup there (Settings → “Data and backups” → export), and here, in the same section, import that file.
  3. Open Settings → “Sync and own server”. The server address is already filled in. Enter the access code from the black window and click “Save and test the connection”. “Connection OK ✓” should appear.
  4. Click “Synchronize now”. The data of this computer has been written to the server.
A common mistake: do not enter your server address in the version of the app on an internet website (an address like …github.io). The browser forbids such pages to contact addresses like http://192.168…. On the computer use the address http://localhost:8787, on the phone use the Android app.

Step 5. Connect the phone

  1. The phone must be connected to the same Wi-Fi as the computer (not to mobile internet and not to a “guest” network).
  2. Open the “Game Catalog” app on the phone → Settings → “Sync and own server”.
  3. In the “Server address” field enter the address from the black window, in full, with http:// and :8787 (for example, http://192.168.0.15:8787). Be careful with the dots and digits.
  4. In the “Access code” field enter the code from the black window.
  5. Tap “Save and test the connection”, then “Synchronize now”. After a few seconds the games from the computer appear on the phone. Covers and screenshots come along with the games; with a big database the first time can take a couple of minutes.
Tip: if you are not sure the address is right, open it in the phone's browser. The catalog page should open. If it did, the network is fine.

How it works from now on

  • “Synchronize automatically” is on by default: the exchange happens when the app starts, when you return to it, a few seconds after your changes, and every couple of minutes while the app is open. The “Synchronize now” button does it immediately.
  • You add a game on the phone: it appears on the computer, and vice versa. Deletions, edits, collections, series, custom properties, the Inbox, covers, screenshots and the shared lists of platforms and genres: everything is transferred.
  • If the same game was changed on two devices before an exchange, the later edit is kept (as a whole). So it is better for the devices to exchange often, and for their clocks to be right (the app aligns them with the server by itself).
  • The “Delete all data” button in the “Danger zone” clears only this device. The copy on the server stays, and at the next sync everything comes back. This is handy if you need to “start over” on a device.
  • Personal settings (filters, view, keys, zoom) stay separate on each device.

Step 6. Connect a second computer (optional)

On another computer on the same network, open the server address in a browser, for example http://192.168.0.15:8787. The same catalog opens. Go to “Settings → Sync and own server”, enter the access code and click “Save and test the connection”. The data is pulled in. As long as the server is on, everything works.

Step 7. Make the server start by itself

So that you do not have to start the server by hand every time, double-click the file “5. Enable autostart”. After that the server starts by itself when you sign in to Windows (in a minimized window). You can undo it with the file “6. Disable autostart”. If you move the GameCatalog folder, run “5. Enable autostart” again.

A permanent address

The computer's address on the network, like 192.168.0.15, sometimes changes after the router restarts. If the app suddenly stops finding the server, open “4. Show address and code”, check whether the address changed and enter the new one in the app. To make the address never change, find “IP address reservation” (or “DHCP: static addresses”, “MAC binding”) in the router settings and fix the address for this computer. How to do it depends on the router model. You can find it on the internet by searching for “ip address reservation” and the router model.

Where the data is, how to make a backup

  • All the server's data is in the folder GameCatalog\data: the file db.json and the folder blobs (covers and screenshots).
  • To make a backup, copy the data folder to a flash drive or the cloud. Once a day the server itself puts a copy of db.json into data\backup (the last 14 are kept).
  • Also make a backup inside the app (export to a file): it is an independent safety net.

IGDB keys on the server (optional)

The web version cannot contact IGDB directly. The server can do it for it. To enable this: stop the server (close the black window), open the file config.json in Notepad (right-click → “Open with” → “Notepad”), put your keys between the quotes in the lines igdbClientId and igdbClientSecret, save the file and start the server again. After the next sync, IGDB search works in the app on any device, and you do not need to enter the keys in the app itself.

How to update the app on the server

  1. Close the black server window.
  2. Download and extract the new archive into any other folder.
  3. Copy the www folder and the file server.mjs from the new archive into C:\GameCatalog, replacing the old ones. Do not touch the data folder and the file config.json: they hold your data and your access code.
  4. Start “2. Start server”. If the browser still shows the old version, press Ctrl+F5.

If something does not work

What you seeWhat to do
“No connection to the server”1) Is the server running? The black window must be open. 2) Are the phone and the computer on the same Wi-Fi? Turn off mobile data and VPN on the phone. 3) Is the address typed exactly, with http:// and :8787? Compare with “4. Show address and code”. 4) Run “3. Allow network access” as administrator.
The address opens on the computer but not on the phoneAlmost always the firewall is to blame: do item 4 above. Also in Windows go to Settings → Network & internet → Wi-Fi → your network and choose the network type “Private”, not “Public”.
“Wrong access code”Type the code without spaces, with the hyphen in the middle. “4. Show address and code” shows it.
“Too many wrong attempts”Wait 10 minutes or restart the server, then enter the correct code.
“Port 8787 is already in use”The server is already running in another window. Close the extra window. Or change the port number in config.json (then use the new number both in the address and in the firewall rule).
The server window closed right awayStart “2. Start server” again and read the message: most often it is “Node.js was not found”, then do step 2.
The antivirus complainsThe server downloads nothing and sends nothing to the internet (except to IGDB, if you set the keys). If your antivirus has its own firewall, allow incoming connections for Node.js on the private network.
New features are not visible after an updatePress Ctrl+F5 in the browser; on the phone update the app to the new version.

Security

  • The server is reachable only inside your home network. Do not forward the port on the router to the internet and do not use this scheme away from home: that needs a different setup (encryption).
  • Data goes over the home network without encryption. That is normal for your own network, but do not connect the server on public networks (cafes, hotels).
  • The access code works like a password: do not share it. To change the code, stop the server, delete the "token" line from config.json (or the whole file), and start the server: a new code appears. Then enter it on your devices.

How to remove everything

Run “6. Disable autostart”, close the black window and delete the GameCatalog folder. If you want to keep the data, copy the data folder first. In the app, tap “Disconnect the server” in the sync settings.
